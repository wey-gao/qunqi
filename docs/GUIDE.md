# 群栖 Qunqi · 使用说明书

自建聊天网关 + WebView 客户端。外观只存本机，内容尽量留在本地，服务器只做同步。

## 安装与连接
- 安装包：服务器 `/api/apk` 或 GitHub Releases。
- 首次打开填服务器地址（默认已内置 `<你的服务器地址:端口>`），再起昵称。
- 旧手机/重装：在设置里输入身份码恢复，成功后会自动重载会话列表。

## 聊天基础
- 发文字、图片、文件、语音、视频；图片点开看原图，长按可下载。
- 长按消息：回复、复制、转发、收藏、多选、撤回（2 分钟内）、编辑（5 分钟内）、删除。
- 多选后可合并转发；单条转发在长按菜单里。
- 群聊里 `@` 面板支持选单个成员或“全体成员”。
- 断网时消息进本机待发送队列，联网自动补发；输入中的草稿按会话本地保存。

## 大文件
- 超过 8MB 自动分片上传（4MB/片），顶部有进度条。
- 断网会保留进度，重新选同一个文件可续传。

## 外观
- 主题、背景、头像、气泡、字号全部只保存在本机，不影响别人。
- 想让所有人统一外观，只能改代码里的默认值，服务器不存个人外观。

## 设备与恢复
- 设置 → 设备列表：能看到自己所有设备，在线/最后活跃时间。
- 可以下线其他设备；下线后那台设备需要用身份码重新恢复。

## 存储与导出
- 设置 → 存储：显示文件数、上传占用、消息条数、缩略图体积。
- 可导出当前会话为 JSON，可清理本机草稿与待发队列。

## 检索
- 聊天记录检索支持筛选：所有人/只看我、全部/图片/含附件、不限时间/近 7 天/近 30 天；可不输关键词只按条件筛。

## 通知
- 后台轮询有新消息会通知；设置里可开“免打扰”，后台不弹通知，进 App 再看。

## 收藏
- 长按消息收藏，存本机，最多 100 条；设置 → 存储 → 查看收藏，可逐条删除。

## 管理员
- 管理员可撤回/编辑他人消息、改群公告、改群背景、移出成员、开关插件、推送更新。
- 超过普通上限的上传需要二次确认（公开模式下强制）。
